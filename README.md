# ✈️ TripWise

> ⚠️ **Status do Projeto:** Este aplicativo está em fase inicial de desenvolvimento. Novas funcionalidades estão sendo adicionadas regularmente.

O **TripWise** é um aplicativo de planejamento de viagens desenvolvido em React Native com Expo Router. O objetivo é permitir que os usuários organizem suas viagens, controlem gastos, planejem passeios e acompanhem a previsão do tempo no destino.

## ✨ Funcionalidades Atuais

- **Gerenciamento de Viagens:** Crie, edite e exclua viagens com informações como destino, meio de transporte e data.
- **Controle Financeiro:** Adicione um orçamento total, registre gastos individuais e acompanhe o saldo restante em tempo real (formatado em Reais).
- **Planejamento de Passeios:** Adicione e remova pontos turísticos ou atividades que deseja realizar.
- **Clima em Tempo Real:** Integração com API para buscar a temperatura atual do seu destino.
- **Interface Moderna:** Suporte a Modo Escuro (Dark Mode) automático e uma Tab Bar flutuante.

## 🚀 Tecnologias Utilizadas

- **React Native** & **Expo**
- **Expo Router** (Navegação baseada em arquivos)
- **AsyncStorage** (Banco de dados local)
- **Axios** (Requisições HTTP para a API de clima)

## 📱 Como Rodar o Projeto

1. Clone este repositório:
   ```bash
   git clone "https://github.com/Diniz011/TripWise.git"
   ```
2. Instale as dependências:
   ```
   npm install
   ```
3. Inicie o aplicativo:
   ```
   npx expo start
   ```
